# 🐾 Catlendar — Календарь передержки домашних животных

Уютное мобильное приложение для Android (на базе **Vue 3, TypeScript, Tailwind CSS и Capacitor**), созданное специально для зоонянь, волонтёров и домашних гостиниц для животных.

---

## ✨ Основные возможности

1. **Милая пастельно-розовая дизайн-система**:
   - Нежные оттенки розовая пудра, клубничное молоко, персик, лаванда, мята.
   - Авторский SVG-логотип со спящим/подмигивающим котиком и календариком.
   - Адаптация под безопасные зоны экранов смартфонов (Safe Area Insets).

2. **Интерактивный календарь текущего месяца**:
   - Занимает основное пространство экрана.
   - Непрерывные горизонтальные полоски диапазонов передержки с закруглениями на датах заезда и выезда.
   - Персональный пастельный цвет для каждого питомца для быстрой наглядности.
   - Поддержка наложения нескольких одновременных передержек по вертикальным слотам.

3. **Двухшаговая механика взаимодействия**:
   - **1-й тап по диапазону**: Всплывает компактный милый тултип прямо над днем с кличкой, породой, датами и статусом оплаты.
   - **2-й тап (по тултипу или повторно по брони)**: Открывает подробную карточку передержки.
   - **Выделение свободных дней**: Нажатие на свободный день (начало) и второй свободный день (конец) подсвечивает период и вызывает кнопку быстрого оформления передержки!

4. **Подробная карточка передержки**:
   - Кличка, аватар, порода, привычки и рацион.
   - Точные сроки и общее количество дней.
   - **Финансы**: тариф в сутки, общая сумма, внесенная предоплата и автоматический расчёт остатка к оплате.
   - Быстрая кнопка «Отметить оплаченным 100%» с салютом из конфетти 🎉.
   - **Контакты хозяина**: имя, телефон с кнопкой прямого звонка (`tel:`), кнопки WhatsApp и Telegram.

5. **Автообновление из приложения (In-App Updater)**:
   - Проверяет свежие релизы через GitHub Releases API (`/releases/latest`).
   - На Android скачивает APK в кэш и запускает системную установку поверх текущей версии.
   - В браузере предоставляет прямую ссылку на скачивание.

6. **Гарантированно статичный ключ подписи (Keystore)**:
   - В проект включён постоянный релизный ключ `android/app/release.keystore`.
   - В `build.gradle` настроен `signingConfigs.release`.
   - При сборке на GitHub Actions приложение всегда подписывается одним и тем же ключом, исключая ошибку `INSTALL_FAILED_UPDATE_INCOMPATIBLE`.

## 🚀 Запуск и разработка

### Локальный запуск в браузере
```bash
npm install
npm run dev
```
Откройте ссылку в браузере (по умолчанию `http://localhost:5173/`).

### Синхронизация изменений с Android
```bash
npm run cap:build
```

## 🛠️ Сборка APK на GitHub Actions

В репозитории настроен готовый GitHub Actions Workflow: [`.github/workflows/build-apk.yml`](.github/workflows/build-apk.yml).

### Способ 1: Автоматическая сборка при создании релиза / тега
```bash
git add .
git commit -m "Релиз версии v1.0.0"
git tag v1.0.0
git push origin main --tags
```
GitHub Actions автоматически:
1. Соберёт веб-бандл.
2. Синхронизирует проект Capacitor.
3. Соберёт релизный APK через Gradle, подписав его статическим ключом.
4. Создаст GitHub Release с прикрепленным файлом `Catlendar-v1.0.0.apk`.

### Способ 2: Ручной запуск (Workflow Dispatch)
1. Перейдите во вкладку **Actions** в вашем репозитории на GitHub.
2. Выберите workflow **«Build and Release Android APK»**.
3. Нажмите **Run workflow**, введите версию (например, `v1.0.1`) и запустите сборку.

## 🔑 Настройка репозитория для автообновлений

1. В приложении откройте **«Настройки»** (иконка шестерёнки в правом верхнем углу).
2. В поле **«Репозиторий на GitHub»** введите адрес вашего репозитория в формате:
   ```text
   ваш-логин/catlendar
   ```
3. Нажмите **«Сохранить»**. Теперь при публикации новых релизов на GitHub пользователи смогут обновиться прямо внутри приложения в 1 тап!
